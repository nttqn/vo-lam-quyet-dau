# Icon Bảo Khố (7 sản phẩm IAP) — ChatGPT, 1 tấm

1. Mở chat ChatGPT mới, dán nguyên prompt bên dưới.
2. Tải ảnh về, đặt tên `bao_kho.png`, thả vào thư mục này (`assets_src/shop/`).
3. Thứ tự icon phải đúng như prompt: hàng trên 4 cái trái→phải, hàng dưới 3 cái. Sai thứ tự hoặc thiếu thì bảo vẽ lại.
4. Chạy `godot --headless --path . --script res://tools/icon_cut.gd -- bao_kho bao_kho_store`
   - `assets/ui/shop/<id>.png` (256): dùng trong màn Bảo Khố của game.
   - `store/iap/<id>.png` (512, nền tối): ảnh sản phẩm cho Play Console.
